# Лабораторная работа: Однослойный перцептрон

## Цель работы
Реализовать алгоритм обучения однослойного перцептрона с нуля (без использования библиотек глубокого обучения), изучить влияние гиперпараметров на процесс оптимизации, провести анализ качества классификации и выполнить расширенные эксперименты.

## Структура проекта
Каждая дополнительная задача реализована в отдельном исполняемом файле. Для удобства проверки и изоляции экспериментов каждый файл содержит независимую реализацию базового класса `Perceptron`, подготовку данных и код соответствующего задания.

- `main_base.py` - базовое задание. Обучение однослойного перцептрона, визуализация его обучения и проведение экспериментов с ним (подбор разных гиперпараметров)
- `main_gen_1_task.py` — Доп. задание 1. Генерация синтетических данных (линейно разделимые, XOR, окружность, шум).
- `main_hinge_loss_2_task.py` — Доп. задание 2. Функция потерь Hinge loss и L2-регуляризация.
- `main_metrics_3_task.py` — Доп. задание 3. Расчёт метрик (Precision, Recall, F1, ROC-AUC) и визуализация ошибок.
- `main_gradient_4_task.py` — Доп. задание 4. Градиентный спуск с моментом (Momentum SGD).
- `main_cross_validation_5_task.py` — Доп. задание 5. K-Fold кросс-валидация и автоматический подбор гиперпараметров.

Все файлы также содержат обязательную часть лабораторной работы: обучение с заданными параметрами, графики функции потерь и эксперименты по влиянию скорости обучения, размера батча и инициализации весов.

## Описание реализации

### Базовый алгоритм (Обязательная часть)
- **Архитектура:** Однослойный перцептрон с сигмоидальной функцией активации.
- **Инициализация:** Веса `w ~ N(0, 0.01)`, смещение `b = 0`.
- **Функция потерь:** Binary Cross-Entropy (BCE) с защитой от логарифма нуля (`eps=1e-7`).
- **Оптимизация:** Mini-Batch Gradient Descent. Градиенты вычисляются векторизованно через операции NumPy.
- **Подготовка данных:** Генерация `make_classification`, стратифицированное разбиение 70/30, Z-score стандартизация признаков.

### Дополнительные задания
**Задание 1. Генераторы данных**
Реализованы функции для создания линейно разделимых кластеров, нелинейно разделимых паттернов (XOR, концентрические окружности) и добавления контролируемого шума. Демонстрируется ограничение линейной модели: перцептрон успешно классифицирует только линейно разделимые выборки.

**Задание 2. Hinge Loss и L2-регуляризация**
- Реализован класс `PerceptronHinge` с преобразованием меток в `{-1, +1}` и оптимизацией Hinge loss.
- Реализован класс `PerceptronL2`, добавляющий штраф `λ||w||²` к BCE и в градиент. Показано влияние коэффициента регуляризации на величину весов и обобщающую способность.

**Задание 3. Метрики качества**
Вычисляются Precision, Recall, F1-score и ROC-AUC на тестовой выборке. Построена ROC-кривая. Визуализированы ошибочно классифицированные точки на фоне разделяющей границы.

**Задание 4. Momentum SGD**
Реализован алгоритм градиентного спуска с инерцией: `v = βv + g`, `w = w - ηv`. Проведено сравнение значений коэффициента инерции `β ∈ {0.0, 0.5, 0.9, 0.99}`. Оптимальный баланс скорости сходимости и стабильности наблюдается при `β=0.9`.

**Задание 5. Кросс-валидация**
Реализована 5-кратная стратифицированная кросс-валидация (`KFold`). Проведён перебор по сетке гиперпараметров (`lr` и `batch_size`). Выбраны параметры с максимальной средней точностью, после чего финальная модель обучена на всей обучающей выборке и оценена на тестовой.

## Ключевые выводы
1. Скорость обучения напрямую влияет на сходимость: слишком малые значения замедляют обучение, большие вызывают осцилляции или расходимость.
2. Размер мини-батча определяет баланс между шумностью градиента (batch=1) и вычислительной эффективностью (batch=256). Значение 32–64 обеспечивает стабильное обучение.
3. Инициализация большими весами приводит к насыщению сигмоиды и исчезновению градиента. Малые случайные веса обеспечивают попадание в линейную зону активации.
4. Однослойный перцептрон ограничен линейными разделяющими поверхностями. Для нелинейных задач требуется расширение архитектуры или использование ядерных методов.
5. Регуляризация L2 и импульс (Momentum) улучшают сходимость и снижают риск переобучения при корректном подборе коэффициентов.
